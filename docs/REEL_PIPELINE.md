# Reel analysis and review

GatherForge analyzes each downloaded video on your computer. Open **Reel manifest**, select a Reel and choose **Analyze Reel**. After analysis, expand **Analysis details** to read the transcript and detected screen text. The details also show the speech model, the audio processed, the number of frames checked and any reported problems. Older analyses may not have all these details; choose **Analyze again** to produce a fresh result.

Automatic text may contain mistakes. Screen text is sampled approximately every two seconds, capped at 64 distributed frames, including the beginning and near the end. Short-lived subtitles between samples can still be missed. Tesseract OCR runs Latin and Arabic-script languages in separate passes and filters isolated low-value fragments; this may also remove legitimate short single-word captions. OCR records sampled timestamps in `analysis.json` and reads verified OCR language data from either `models/bundled` or `models/installed`. English (`eng`), Persian (`fas`), and Arabic (`ara`) are available as small, pinned local models in Settings. Missing languages are not fabricated. `no_text` means nothing survived OCR filtering, not that the video contains no text. `partial` or `error` means some work failed. Always verify the video and transcript before approving a category.

Speech uses the selected local Whisper model, by default the bundled Tiny model, which can mishear names, accents, and fast speech. Optional Base Q5 (~60 MB) and Small Q5 (~190 MB) multilingual models are pinned in the AI catalog. Use **Install / repair** for the desired model, select it under **Managed speech model**, then analyze again. They are not downloaded by default and cannot guarantee exact transcription. Set **Speech language → English** in Settings for an English-language Reel instead of relying on automatic language detection. Audio is processed in 60-second segments instead of stopping at 100 seconds; words across segment boundaries can be missed or repeated. Results show the processed duration when available. Transcription has a 20-minute processing limit, a two-hour audio limit, and a 30,000-character text limit. If a limit or failure is reached the result is marked `partial` or `error` instead of silently reporting a complete transcript. Depending on the computer and model, long videos can take time.

The optional visual stage examines one frame when other text evidence is sparse. `Visual analysis: skipped — text evidence sufficient` is a deliberate routing decision, not an OCR or speech failure; it does not mean the text is accurate. A category suggestion may use excerpts from the caption, speech, screen text and visual description; the full available transcript and OCR results remain in the analysis details. Suggestions require your review.

## Choosing local speech and OCR models

In Settings, select **Existing local model** for Speech or OCR and expand **Local model override paths and API**. Put a compatible Whisper `.bin` or `.gguf` file inside the app's `models` directory and enter its path for Speech. For OCR, enter a directory inside `models` containing one or more `eng.traineddata`, `ara.traineddata`, or `fas.traineddata` files. Relative paths are interpreted from `models`. Click **Save AI configuration** and analyze again. A larger compatible Whisper model (for example, a multilingual base or small model from the official whisper.cpp model set) may improve transcription but can be slower and require more memory; results depend on the recording. Only install source-reviewed models you trust, and keep model files under the app's `models` directory. A missing or invalid model is reported as unavailable.

Disabling a stage skips it. API mode is not implemented for these stages and does not upload media. The app does not download a larger Whisper model as part of this patch. The optional visual stage has separate availability requirements.

## Approval and files

`manifest.json` tracks the original URL, video filename, size and SHA-256. `analysis.json` stores the analysis stages, evidence and review status. Reanalyzing resets that Reel's approval, so review and approve it again before using the unsave action. The original video stays in place. Approval verifies its hash and creates a verified organized hard link. Unsave is a separate explicit action guarded by approval, matching metadata and the organized link.

The Rust UI runs `tools/reel_analysis.py` for local inspection and filing. On Unix, cancellation and the overall 30-minute time limit also stop the analysis subprocess group. Speech, OCR and optional visual inference depend on their local runtimes and model files. No video or audio is sent to a hosted speech or OCR service by this pipeline. Live Instagram behavior, installed runtimes and model accuracy must be checked in the user's environment.
