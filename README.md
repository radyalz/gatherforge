# GatherForge

Native Rust desktop media workspace built using egui.

Features:
- Modern component-based interface
- Music library scanning
- Main-artist identification from filenames
- Possible duplicate detection
- Single-track and playlist downloading using yt-dlp
- Cross-platform Rust build workflow

Run with:

cargo run --release

See docs/ for component and design rules.

This version migrates the current Rust prototype.
Advanced staging, publish/restore and Excel reports from the previous
Go application have not yet been ported.
